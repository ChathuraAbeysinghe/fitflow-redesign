# ADR-001: Use Firebase instead of a self-managed PostgreSQL backend for the MVP

| Field | Detail |
|---|---|
| **ADR ID / Title** | ADR-001: Use Firebase instead of a self-managed PostgreSQL backend for the MVP |
| **Status** | Accepted |
| **Context** | The FitFlow team is small and has a limited development time. The app needs real time updates, offline support, and secure data handling while keeping infrastructure management simple. |
| **Decision** | Use Firebase Firestore for storing data and Firebase Realtime Database for live social features, together with Firebase Auth. |
| **Consequences** | **Positive:** Faster development, built-in real time features, easier scaling, and lower maintenance. **Negative:** Less flexibility for complex database queries and some dependency on Firebase. |
| **Alternatives Considered** | Node.js + PostgreSQL + Auth0 and FastAPI + PostgreSQL + AWS Cognito were considered, but Firebase was selected because it is simpler and faster for the MVP. |
