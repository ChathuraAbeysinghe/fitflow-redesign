# fitflow-redesign
FitFlow app redesign - IT3060 HCI Lab Sheet 5

Cross-platform redesign of the FitFlow fitness app, built with React Native, Node.js/Express,
and Firebase.

## Tech stack
- Frontend: React Native
- Backend: Node.js + Express
- Database: Firebase Firestore + Realtime Database
- Auth: Firebase Auth
- AI: TensorFlow Lite (on-device) + Cloud AI service; ML Kit for nutrition photo recognition

## Documentation
See /docs for the full research, design, testing, and architecture trail (Lab Sheets 1-5),
including the technology comparison tables, weighted decision matrix, and the Architecture
Decision Record in /docs/architecture.

## Getting started
1. cd frontend && npm install && npm run start
2. cd backend && npm install && npm run dev
3. Configure Firebase credentials in .env (see .env.example)
